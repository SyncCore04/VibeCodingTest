# 更新日志

## v1.0.0 — 2026-08-19

### 项目更名
- 项目正式命名为 **回映 / Rewind**

### 新增功能

#### 1. 观看记录系统
- 新增 `watch_sessions` 表，记录每次播放的开始时间、结束时间、观看时长、是否看完
- 播放进度超过 90% 自动标记为"已看完"
- 仪表盘展示最近 20 条观看记录

#### 2. 断点续播
- 新增 `progress` 表，按设备+视频记录播放位置
- 播放时每 5 秒自动上报进度，暂停和页面关闭时也会保存
- 再次打开同一视频自动从上次位置继续，弹出续播提示（可选择从头播放）
- 视频列表显示"续播 XX:XX"徽章，已看完显示"✓ 已看完"
- 使用 `navigator.sendBeacon()` 确保页面关闭时数据不丢失

#### 3. 设备识别与管理
- 新增 `devices` 表，通过 Cookie + UUID 识别访问设备（无需登录）
- 记录设备 IP、User-Agent、首次/最近访问时间
- 仪表盘可查看所有设备，支持给设备打标签（如"客厅电视""我的手机"）

#### 4. 后台仪表盘 (`/admin`)
- 5 个统计卡片：设备数、播放次数、总观看时长、看完数、看过的视频数
- 近 14 天观看趋势柱状图（Chart.js）
- 最多观看视频 Top 10 排行榜（金银铜牌样式）
- 设备管理面板：设备信息、播放统计、标签编辑
- 最近观看记录时间线

### 技术变更

#### 数据库
- 引入 SQLite（Python 内置 `sqlite3`，零依赖）
- 三张表：`devices`、`progress`、`watch_sessions`
- 开启 WAL 模式支持并发读写
- 数据库文件 `rewind.db` 自动创建在程序同目录

#### 后端 API（新增 8 个接口）
| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/progress` | GET | 获取单视频播放进度 |
| `/api/progress/all` | GET | 获取本设备所有视频进度 |
| `/api/progress` | POST | 保存播放进度 |
| `/api/play` | POST | 创建播放会话 |
| `/api/end` | POST | 结束播放会话 |
| `/api/stats` | GET | 仪表盘统计数据 |
| `/api/devices` | GET | 设备列表 |
| `/api/devices/<id>/tag` | POST | 更新设备标签 |

#### 前端
- `index.html`：新增续播逻辑、进度上报、进度徽章、仪表盘入口
- 新增 `admin.html`：完整仪表盘页面
- 深色主题统一，响应式适配移动端

### 文档
- 新增 `README.md`：项目说明、快速开始、配置指南
- 新增 `技术文档.md`：面向初学者的完整技术解析（12 章）
- 新增 `拓展规划.md`：9 个未来拓展方向 + 可直接使用的 AI 提示词

### 修复与优化
- 修复 `启动服务器.bat` 和 `打包.bat` 的 Python 路径问题（适配多 Python 环境）
- 视频流仍使用 `send_file(conditional=True)` 支持 HTTP Range 拖动进度条
- 路径遍历防护保持不变

## v0.1.0 — 2026-08-16

- HTTP Range 支持，可拖动进度条

- 路径遍历安全防护
- PyInstaller 单文件打包支持
