# DesktopPet 桌面宠物

一个基于 PyQt5 的 Windows 桌面宠物程序。角色图片以透明无边框窗口的形式悬浮于桌面，支持拖动、点击互动、对话气泡、滚轮缩放等操作，打包为单文件 EXE 后可双击直接运行。

## 功能特性

- **透明置顶窗口** — 无边框、背景透明、始终置顶，角色如贴纸般悬浮于桌面
- **鼠标拖动** — 左键按住角色任意位置即可拖动，松开后窗口停在新位置
- **点击互动** — 左键单击角色轮流触发三种动画：跳跃（抛物线）、压扁回弹、左右抖动
- **对话气泡** — 互动时随机弹出一条中文台词，白色不透明圆角气泡带三角尾巴，显示在角色上方，3 秒后淡出消失
- **滚轮缩放** — 鼠标滚轮上下滚动实时调整角色大小，范围 60px ~ 400px
- **右键菜单** — 包含调整大小（小/中/大/超大四档）、置顶开关、退出程序

## 技术栈

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | 3.10+ | 运行环境 |
| PyQt5 | 5.15.x | GUI 框架，提供窗口、动画、绘图能力 |
| PyInstaller | 6.x | 将 Python 脚本打包为单文件 EXE |

## 项目结构

```
desktop_pet/
├── desktop_pet.py      # 主程序源代码
├── pet.png             # 角色图片（透明背景 PNG）
├── build.bat           # 一键打包脚本
└── dist/
    └── DesktopPet.exe  # 打包后的可执行文件
```

## 快速开始

### 方式一：直接运行 EXE

双击 `dist/DesktopPet.exe`，角色会出现在屏幕右下角，即可开始使用。

### 方式二：从源码运行

需要先安装依赖：

```bash
pip install PyQt5
```

然后运行：

```bash
python desktop_pet.py
```

## 使用说明

| 操作 | 效果 |
|------|------|
| 左键单击角色 | 触发互动动画（跳跃/压扁/抖动轮流切换）+ 随机对话气泡 |
| 左键拖动角色 | 移动宠物到桌面任意位置 |
| 鼠标滚轮 | 放大或缩小角色 |
| 右键单击角色 | 打开菜单 |

右键菜单选项：

- **调整大小** — 子菜单提供 80px、150px、250px、400px 四档预设
- **置顶开关** — 切换窗口是否始终置顶于其他窗口之上
- **退出程序** — 关闭并退出

## 重新打包

如需修改源代码后重新生成 EXE，双击 `build.bat` 或手动执行：

```bash
python -m PyInstaller --noconsole --onefile --add-data "pet.png;." --name "DesktopPet" desktop_pet.py
```

打包产物位于 `dist/DesktopPet.exe`。图片资源已通过 `--add-data` 内嵌进 EXE，运行时不依赖外部文件。

## 实现要点

- **透明窗口** — 使用 `Qt.FramelessWindowHint` 去除边框，`WA_TranslucentBackground` 启用透明背景，`WindowStaysOnTopHint` 实现置顶
- **点击与拖动区分** — 鼠标移动距离超过 5px 判定为拖动，否则视为点击触发互动
- **动画系统** — 基于 `QPropertyAnimation` 对窗口 `geometry` 属性做关键帧动画，三种动画通过计数器轮流触发
- **对话气泡** — 独立的透明子窗口，用 `QPainter` 手绘圆角矩形和三角尾巴，通过 `windowOpacity` 属性动画实现淡入淡出
- **资源路径兼容** — `resource_path()` 函数检测 `sys._MEIPASS`，确保打包后能正确访问内嵌图片
